# marketing

Único árbol vivo de marketing de este repo.

- `App Store/` — metadata actual, PNGs iPhone/iPad ES/EN, scripts en uso
- `screenshots-appstore/` — generador de capturas y post diario
- `remotion/` — **estudio de demos en vídeo**: footage real del iPhone + motion estilo
  Apple, renderizado por código. Piezas 9:16 y 16:9 del pack 2.1.
  Empieza por [`remotion/docs/OPERACION.md`](remotion/docs/OPERACION.md).

Los tres son hermanos y no se reemplazan: el generador saca **capturas** para la ficha,
Remotion saca **vídeo** para redes.

`Web/` permanece en la raíz del repo (sitio independiente).
